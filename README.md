# 🌱 Eco-Friendly Product Sales Prediction

An end-to-end Machine Learning project that predicts weekly sales of eco-friendly products using a Linear Regression model. The application is built with **Streamlit** and provides an interactive dashboard for sales forecasting.

## 🚀 Live Demo

👉 https://your-app-name.streamlit.app

---

## 📌 Project Overview

This project helps businesses estimate future weekly sales based on operational and environmental factors such as:

- Region
- Average Temperature
- Google Trend Score
- Marketing Spend
- Store Visits
- Holiday Week
- Date Features (Day, Month, Quarter, Year)

The trained Machine Learning model predicts weekly sales and also estimates monthly, quarterly, and yearly sales.

---

## ✨ Features

- 🌱 Interactive Streamlit Dashboard
- 📅 Automatic Date Feature Extraction

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Eco-Friendly-Product-Sales-Prediction.git
```

Go to the project directory

```bash
cd Eco-Friendly-Product-Sales-Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
